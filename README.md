# 🍽 ChefBot — кухонный помощник как Telegram Mini App

Не бот с меню на кнопках, а полноценное веб-приложение внутри Telegram:
свои экраны, свой дизайн, плавная навигация. Решает главный вопрос —
**«что приготовить сегодня?»** — по категориям, по продуктам из
холодильника, по бюджету/времени, случайным выбором.

Статус: **версия 1.0 (MVP)**. Функция подсчёта остатков продуктов
сознательно не реализована.

## Как это устроено

```
Telegram-клиент
     │
     │ открывает Mini App (WebView) по HTTPS-адресу
     ▼
webapp/  (HTML/CSS/JS, без сборки)  ──fetch──▶  backend/ (FastAPI)
                                                     │
                                                     ▼
                                              database.db (SQLite)

bot/bot.py — отдельный процесс: aiogram-бот, который только открывает
             Mini App (/start, кнопка меню чата) и даёт админ-панель
```

`backend/main.py` одновременно отдаёт API (`/api/*`) и статику
мини-приложения (`webapp/`), поэтому это один сервис на одном домене —
для CORS не нужно ничего настраивать. `bot/bot.py` — отдельный лёгкий
процесс, использующий ту же базу данных.

## Возможности

- 🥣 Категории блюд с быстрым переходом к спискам рецептов
- 👨‍👩‍👧 Пересчёт ингредиентов под нужное число порций
- 👨‍🍳 Пошаговый режим готовки с прогресс-баром и таймерами
- 🥕 «Мой холодильник» — отметь, что есть дома, получи рецепты,
  отсортированные по % совпадения продуктов, с указанием, чего не хватает
- 🔎 Поиск по названию блюда и по ингредиенту (корректно работает с кириллицей)
- ❤️ Избранное, 🛒 список покупок с отметками купленного
- 🎲 Случайный рецепт
- 🛠 Админ-панель прямо в Telegram (бот): статистика, рассылка,
  добавление/скрытие рецептов — без правки кода

## Установка

Подробная пошаговая инструкция «с нуля» (для тех, кто делает это впервые)
— в **[INSTALL.md](INSTALL.md)**: получение токена, настройка `.env`,
HTTPS-адрес для Mini App, запуск и решение частых проблем.

Кратко, если вы уже понимаете, что делаете:

```
pip install -r requirements.txt
cp .env.example .env        # заполните BOT_TOKEN, ADMIN_IDS, WEBAPP_URL
python -m scripts.seed_db   # наполнить базу рецептами

# два процесса параллельно:
uvicorn backend.main:app --host 0.0.0.0 --port 8000
python -m bot.bot
```

Главное — `WEBAPP_URL` должен быть настоящим `https://` адресом (Telegram
не откроет Mini App по http); для быстрой проверки на своём компьютере
подойдёт `ngrok http 8000`. Всё это подробно разобрано в INSTALL.md.

Для постоянного запуска (без ngrok, 24/7) — отдельная инструкция именно
под Timeweb Cloud: **[TIMEWEB_DEPLOY.md](TIMEWEB_DEPLOY.md)** (что купить,
как создать сервер, настроить HTTPS через Caddy и автозапуск через
systemd). Общий подход для любого другого хостинга — в разделе
«Постоянный запуск» в [INSTALL.md](INSTALL.md#постоянный-запуск-без-ngrok).

## Как добавлять рецепты (до 2000–2500 штук)

**А. Через админ-панель в боте (без кода).** Команда `/admin` →
«➕ Как добавить рецепт» — бот пришлёт шаблон JSON. Заполните и отправьте
отдельным сообщением — рецепт сразу в базе.

**Б. Массово через файл.** Добавляйте объекты в `data/seed_recipes.json`
(или отдельный файл в том же формате) и выполните:

```
python -m scripts.seed_db --file data/мой_файл.json
```

Скрипт идемпотентен — рецепты с уже существующим названием пропускаются.

## Структура проекта

```
RecipeApp/
├── backend/
│   ├── main.py          # FastAPI: /api/* + раздача webapp/
│   ├── config.py          # конфигурация из .env
│   ├── auth.py              # проверка подписи Telegram initData
│   ├── schemas.py             # Pydantic-модели ответов API
│   ├── utils.py                 # пересчёт порций
│   └── database/
│       ├── models.py             # ORM-модели (SQLAlchemy)
│       ├── db.py                   # engine/сессии + Unicode-safe LOWER
│       └── crud.py                   # функции доступа к данным
├── bot/
│   └── bot.py             # тонкий бот: запуск Mini App + админка
├── webapp/
│   ├── index.html          # разметка экранов (шаблоны <template>)
│   ├── styles.css            # дизайн (без UI-фреймворков)
│   └── app.js                  # роутинг экранов, вызовы API, Telegram SDK
├── data/
│   └── seed_recipes.json   # рецепты-затравка (расширяется без кода)
├── scripts/
│   ├── seed_db.py            # импорт рецептов в БД
│   └── dev-tunnel.ps1          # авто-туннель для точечной проверки в Telegram
├── requirements.txt
├── .env.example
├── README.md
├── INSTALL.md                 # подробная пошаговая установка
├── TIMEWEB_DEPLOY.md            # постоянный запуск на Timeweb Cloud
└── database.db               # создаётся автоматически при первом запуске
```

## Технологии

- **Backend:** Python 3.12, FastAPI, SQLAlchemy 2.0 (async), SQLite (aiosqlite)
- **Бот:** aiogram 3.x
- **Фронтенд:** без сборки — HTML/CSS/vanilla JS + официальный
  [Telegram Web App SDK](https://core.telegram.org/bots/webapps)

## Дизайн мини-приложения

Тёплая «кухонная» палитра (приглушённый шалфей, кирпично-томатный и
горчичный акценты) вместо шаблонной AI-эстетики, категории оформлены как
баночки со специями, карточки рецептов — с перфорацией по левому краю,
как у рецептных карточек. Тема автоматически подстраивается под
светлую/тёмную тему Telegram.

## Безопасность

Каждый запрос к API проверяет подпись `Telegram.WebApp.initData` (HMAC по
официальному алгоритму Telegram) — подделать пользователя, не зная токен
бота, нельзя. `DEV_MODE=true` отключает эту проверку для локальной отладки
в обычном браузере — не включайте его в проде.
